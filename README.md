# 🎮 Personagem AI

<img width="1920" height="879" alt="image" src="https://github.com/user-attachments/assets/494575ed-f00d-4f73-82a9-619d80e7dd13" />

Uma experiência interativa que permite escolher personagens ilustrados ou transformar uma foto em um personagem com estilo de videogame usando inteligência artificial.

## ✨ Funcionalidades

- 🧑‍🎤 **Seleção de personagens:** escolha entre Lucia, Jason e CJ.
- 📸 **Envio de foto:** selecione uma imagem do seu dispositivo.
- 🤖 **Geração com IA:** transforme a foto em uma ilustração com contornos marcantes e cores vibrantes.
- 🎨 **Interface dinâmica:** o nome e a cor do personagem mudam conforme a seleção.
- 🖥️ **Aplicação web:** desenvolvida com tecnologias front-end.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Puter.js](https://js.puter.com/)
- Google Fonts
- IA para geração de imagens

## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/raquelgoncalo/personagem-ai.git
   ```

2. Entre na pasta:

   ```bash
   cd personagem-ai
   ```

3. Abra o arquivo `index.html` no navegador ou execute o projeto usando a extensão Live Server do VS Code.

4. Escolha um dos personagens disponíveis ou envie uma foto para experimentar a geração de imagens com IA.

**Observação:** é necessária uma conexão com a internet para carregar a biblioteca Puter.js e utilizar os serviços externos de geração de imagens. A disponibilidade da geração depende do serviço utilizado.
